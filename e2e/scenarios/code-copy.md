## Steps
1. Close any welcome or tour dialog that is shown.
2. Send: "Give me a one-line bash command that lists files, in a code block."
3. Wait until the answer has finished streaming.
4. Click the copy button of the code block.

## Expected
- The code is shown with syntax highlighting in a code box.
- After clicking, the button shows copy feedback (icon change or toast).
