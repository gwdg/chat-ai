## Steps
1. Close any welcome or tour dialog that is shown.
2. Find the theme toggle and switch the theme.
3. Switch it back.

## Expected
- After each switch the whole page changes between light and dark colors.
- Text stays readable with sufficient contrast in both themes.
- No part of the page (sidebar, header, prompt box) keeps the old theme.
