## Steps
1. Close any welcome or tour dialog that is shown.
2. Send: "Write a 1000-word essay about the history of computing."
3. While the answer is still streaming, click the stop button.

## Expected
- Streaming stops and the partial answer stays visible.
- The send button is available again and the prompt box accepts input.
- No error message is shown.
