## Steps
1. Close any welcome or tour dialog that is shown.
2. Open the settings panel.
3. Open the help (question mark) of the temperature setting, read it, close it.
4. Do the same for the system prompt help.

## Expected
- Each help dialog shows an explanatory text with a title.
- Each dialog closes and returns to the settings panel.
